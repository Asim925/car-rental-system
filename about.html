About DriveEase

Making car rental simple and accessible.

Our purpose

Finding a suitable rental car can be difficult when customers have to contact different rental services individually to compare vehicles, prices and availability. DriveEase organizes this information in one place to make the process simpler, faster and more accessible.

We are a fictional car rental service created as an ICT academic project. It shows practical web development with HTML, CSS and JavaScript, using an original design built from scratch.

What we value

Clarity

Prices, specs and terms are shown up front, so renters know what they are choosing.

Accessibility

The site works on phones and desktops, supports keyboard navigation and uses readable colour contrast.

Simplicity

Three steps from browsing to a request. Each page does one job.

Project scope

DriveEase is an academic prototype. It demonstrates browsing, filtering, cost calculation and request forms. Live availability, online payments and a real customer database are outside the current scope.
